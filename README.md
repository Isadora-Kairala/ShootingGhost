## Como jogar 👻

Para jogar **Shooting Ghost**, utilize as setas direcionais do teclado para movimentar o personagem e o mouse para mirar e atirar nos fantasmas. O desafio é ser ágil, evitar os inimigos e tentar alcançar a maior pontuação possível. O controle é simples: movimente-se com as setas e atire com o mouse.

---

## Sobre o jogo 👻

**Shooting Ghost** é um jogo de ação em 2D desenvolvido como projeto acadêmico para a disciplina de **Introdução à Computação**, no curso de **Ciência da Computação**. O projeto foi criado utilizando a versão gratuita do **Construct 3**, uma plataforma online para criação, programação e publicação de jogos. O jogo foi publicado para acesso livre, possibilitando que qualquer pessoa possa jogar e competir por pontuações.

---

## Firebase 👻

O jogo foi integrado ao **Firebase**, uma plataforma do Google utilizada para o desenvolvimento de aplicações com suporte a banco de dados em tempo real. Essa integração permite que as pontuações dos jogadores sejam armazenadas e sincronizadas instantaneamente. O jogo coleta o nome e a pontuação do jogador que possibilita a comunicação com servidores externos. Assim, é possível construir um ranking de pontuações atualizado em tempo real.
